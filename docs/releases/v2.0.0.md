# DJ Donut v2.0.0

2026-11-17 · [English](#english) · [繁體中文](#繁體中文)

## English

DJ Donut 2.0.0 introduces a compact Discord player, a complete control menu, and automatic song titles in voice channel statuses.

### What's new

- **Components V2 player:** one card with track information, cover art, playback time, progress, requester, voice channel, and queue count. Five main buttons provide shuffle, replay the current song, pause/resume, skip, and favorite.
- **Eleven controls:** volume, repeat, rewind 15 seconds, forward 15 seconds, queue, autoplay, EQ, speed, Sing Along, lyrics, and stop. Volume accepts 0–200%; EQ and speed use private selection panels. The menu displays current settings.
- **Playback speed:** choose 0.5×, 0.75×, 1.0×, 1.25×, 1.5×, 1.75×, or 2.0× while preserving pitch. Progress follows media time at the selected speed. Nightcore and Vaporwave keep their separate pitch effects.
- **Sing Along:** show synchronized lyric excerpts directly on the player, refreshed approximately every five seconds while playing. The Lyrics control provides a separate lyrics view.
- **Voice channel status:** automatically show `🎵 Song title`, switch to `⏸️ Song title` on pause, update on track changes, and clear or transfer the status when playback ends, the bot leaves or moves, or the bot shuts down normally. Status updates are deduplicated and protect another cluster bot's newer status during handoff.
- **Shared audio controls:** Native FFmpeg and Lavalink support volume, seeking, EQ, and speed. Seeking and effect changes preserve pause state; failed changes restore settings where possible.
- **Interaction fixes:** progress updates follow replacement `/nowplaying` messages; controls remain usable while a card refresh is pending; late lyrics and position updates cannot be applied to a different song.
- **Six interface languages:** English, Traditional Chinese, Simplified Chinese, Japanese, Korean, and Spanish.
- **Docker CI repair:** corrected the Buildx action reference so the container build validation can run.

### Upgrade and permissions

No new dependencies, environment variables, or database migrations are required beyond the existing project requirements. Keep your existing `.env` and `data/` directory.

For an existing Git checkout and Docker Compose deployment:

```bash
git fetch origin --tags
git switch --detach v2.0.0
docker compose up -d --build
```

For a Python deployment, select the same tag, install `requirements.txt`, then restart the bot with your existing service manager or `python3 main.py`. Play a new song or run `/nowplaying` to create the new player.

Grant **Set Voice Channel Status** to use automatic song titles. Clearing a status after disconnection may also require **Manage Channels**. Missing status permissions or API failures do not stop music playback.

### Behavior and limits

- Discord controls the background, fonts, icons, and layout according to the listener's theme. The progress bar is a display; use rewind/forward or `/seek` to change position.
- Live streams or tracks with unknown duration cannot seek. Sing Along requires available synchronized lyrics.
- Voice statuses apply to standard voice channels, skip Stage channels, and are limited to 500 characters. Channel names are unchanged.
- Speed and Sing Along are room session settings and reset after a bot restart. Existing persisted settings and queue recovery remain available.

### Validation

105 automated tests pass, including 17 voice status tests. Ruff and whitespace checks pass. FFmpeg accepts all nine EQ presets; audio checks cover playback speed and its composition with Nightcore/Vaporwave. Live Discord appearance and voice connectivity have not been verified. Mypy still reports five pre-existing errors in `core/dave_patch.py` and the search followup return type in `commands/music.py`.

## 繁體中文

DJ Donut 2.0.0 帶來精簡的 Discord 播放卡片、完整控制選單，以及自動顯示歌名的語音頻道狀態。

### 新增功能

- **Components V2 播放介面**：單張卡片整合歌曲資訊、封面、播放時間、進度、點播者、語音頻道與待播數量。五個主要按鈕提供打亂、重播目前歌曲、暫停／繼續、下一首與收藏。
- **11 項控制選單**：音量、循環、倒退 15 秒、快轉 15 秒、待播清單、自動接歌、EQ、速度、跟唱、歌詞與停止。音量可輸入 0–200%；EQ 與速度使用私人選擇面板，選單會顯示目前設定。
- **播放速度控制**：可選 0.5×、0.75×、1.0×、1.25×、1.5×、1.75× 或 2.0×，調整快慢時保持音高，進度依實際歌曲時間計算。Nightcore 與 Vaporwave 的音高效果獨立保留。
- **跟唱模式**：直接在播放卡片顯示同步歌詞片段，播放時約每五秒更新。歌詞選項另外提供獨立歌詞畫面。
- **語音頻道歌名狀態**：自動顯示 `🎵 歌名`，暫停時顯示 `⏸️ 歌名`；換歌自動更新，播完、離開、換房或正常關閉機器人時清除或轉移狀態。避免重複更新，並保護多機器人交接時新機器人顯示的狀態。
- **雙引擎共用音訊控制**：Native FFmpeg 與 Lavalink 支援音量、跳轉、EQ 與速度；跳轉及音效切換保留暫停狀態，操作失敗時盡可能回復原設定。
- **互動穩定性修正**：`/nowplaying` 換卡後進度會跟隨新訊息；卡片刷新期間仍可操作控制；延遲返回的歌詞與播放位置不會套用到另一首歌。
- **六種介面語言**：英文、繁體中文、簡體中文、日文、韓文與西班牙文。
- **Docker CI 修正**：修正 Buildx action 的引用位置，讓容器建置驗證可以執行。

### 升級方式與權限

沿用專案既有需求，不新增相依套件、環境變數或資料庫遷移。請保留原本的 `.env` 與 `data/` 目錄。

使用既有 Git 儲存庫與 Docker Compose 部署時：

```bash
git fetch origin --tags
git switch --detach v2.0.0
docker compose up -d --build
```

使用 Python 部署時，切換至相同標籤，安裝 `requirements.txt` 後，以原本的服務管理工具或 `python3 main.py` 重新啟動。播放新歌曲或執行 `/nowplaying` 即可產生新版卡片。

自動歌名狀態需要授予機器人「**設定語音頻道狀態**」（Set Voice Channel Status）權限；離開後的清除操作也可能需要「**管理頻道**」（Manage Channels）。缺少狀態權限或 Discord API 失敗不會中斷音樂播放。

### 行為與限制

- 背景、字型、圖示與排版由 Discord 使用者主題決定。進度條僅供顯示，跳轉請使用倒退／快轉或 `/seek`。
- 直播或長度未知的歌曲無法跳轉；跟唱模式需要可用的同步歌詞。
- 語音狀態只適用於一般語音頻道，舞台頻道略過，上限為 500 字元；不會修改頻道名稱。
- 速度與跟唱屬於房間工作階段設定，機器人重新啟動後回復預設；既有持久化設定與隊列恢復功能仍可使用。

### 驗證結果

105 項自動化測試通過，包含 17 項語音頻道狀態測試；Ruff 與空白格式檢查通過。FFmpeg 可執行全部 9 種 EQ 設定，並已測試播放速度及其與 Nightcore／Vaporwave 的組合。尚未在實際 Discord 驗證外觀與語音連線。Mypy 仍有 `core/dave_patch.py` 與 `commands/music.py` 搜尋 followup 回傳型別共 5 項既有錯誤。
