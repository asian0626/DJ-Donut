# 播放介面

播放歌曲或使用 `/nowplaying` 時，DJ Donut 會送出 Discord Components V2 播放卡片：

- 上方顯示播放／暫停狀態、歌曲連結、演出者及封面。
- 中間顯示已播放時間、總時長與進度條；直播顯示 LIVE。
- 主按鈕依序為打亂待播清單、重播目前歌曲、暫停／繼續、下一首、收藏。
- 下拉選單提供待播清單、歌詞、循環、音量增減、自動接歌、播放收藏及停止／離開。
- 底部顯示點播者、語音頻道及待播歌曲數量。

進度在播放期間每 15 秒更新一次；暫停、繼續與跳轉會更新卡片。重播按鈕會重新播放目前歌曲。循環模式、目前音量與自動接歌狀態可在下拉選單的選項說明查看。

Discord 決定卡片的背景、字型、按鈕樣式與手機排版；使用者主題會影響實際外觀。機器人無法指定截圖中的整體漸層背景或綠色膠囊標籤，因此播放狀態使用綠色圓點表示。進度條是顯示用途，Discord 機器人訊息不支援可拖曳滑桿；跳轉請使用 `/seek`。

更新並重新啟動機器人後，播放新歌曲或執行 `/nowplaying` 即可產生新版卡片。無須新增環境變數或升級既有需求（專案已要求 discord.py 2.7 以上）。
