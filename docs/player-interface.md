# DJ Donut 2.0.0 播放介面

[繁體中文](player-interface.md) · [English](player-interface.en.md) · [README](../README_zh-TW.md) · [v2.0.0 發行說明](releases/v2.0.0.md)

## 卡片配置

播放歌曲或使用 `/nowplaying` 時，DJ Donut 會送出 Discord Components V2 播放卡片：

- 上方顯示播放／暫停狀態、歌曲連結、演出者及封面。
- 中間顯示已播放時間、總時長與進度條；直播顯示 LIVE。
- 主按鈕依序為打亂待播清單、重播目前歌曲、暫停／繼續、下一首、收藏。
- 下拉選單依序提供音量、循環模式、倒退 15 秒、快轉 15 秒、待播清單、自動接歌、等化器、速度、跟唱模式、歌詞及停止。
- 底部顯示點播者、語音頻道及待播歌曲數量。

進度在播放期間定期更新；暫停、繼續與跳轉會更新卡片。重播按鈕會重新播放目前歌曲。

## 控制選單與速度

選單中的音量、循環模式、等化器與速度會顯示目前設定。音量可以輸入 0 至 200 的整數，100 為一般音量；循環可切換關閉、單曲及整份待播清單。倒退與快轉會移動目前歌曲的播放位置，直播音訊無法跳轉。

自動接歌會在待播清單結束後推薦相似歌曲。等化器提供重低音、Nightcore、8D 等音效；速度控制可調整播放快慢並保持原有音高。Nightcore 與 Vaporwave 本身包含音高變化，屬於獨立音效設定。

速度可選擇 0.5×、0.75×、1.0×、1.25×、1.5×、1.75× 或 2.0×。速度與跟唱狀態套用於目前房間的工作階段；停止並離開、重置房間或重新啟動機器人後，會回復 1.0× 與跟唱關閉。

跟唱模式會在卡片中顯示隨播放位置更新的同步歌詞片段；歌曲必須有可用的同步歌詞。歌詞選項另外提供完整歌詞。停止會清空播放與待播清單，並讓機器人離開語音頻道。這些功能沿用專案的 DJ 權限設定，不需要投票、訂閱或限時使用。

## 語音頻道歌曲狀態

播放時，語音頻道狀態會自動顯示 `🎵 歌名`；暫停時改成 `⏸️ 歌名`。換歌會更新狀態，播完、停止、離開或正常關閉機器人時會清除；移動房間時會清除原房間並更新新房間。歌名過長會截斷至 Discord 的 500 字元上限，頻道名稱不會改變。

請授予機器人「設定語音頻道狀態」（Set Voice Channel Status）權限；離開後的清除操作也可能需要「管理頻道」。若缺少權限或 Discord API 暫時失敗，會記錄錯誤並讓播放繼續。此功能適用於一般語音頻道，舞台頻道略過。

## Discord 外觀限制

Discord 決定卡片的背景、字型、按鈕樣式與手機排版；使用者主題會影響實際外觀。機器人無法指定截圖中的整體漸層背景或綠色膠囊標籤，因此播放狀態使用綠色圓點表示。進度條是顯示用途，Discord 機器人訊息不支援可拖曳滑桿；跳轉可使用選單中的倒退／快轉或 `/seek`。

## 升級至 2.0.0

1. 正常停止機器人，保留現有 `.env`、`data/` 與自訂設定。
2. 將工作目錄更新至 2.0.0 程式碼。Python 部署沿用 `requirements.txt` 與既有啟動方式；Docker 部署使用 `docker compose up -d --build` 重建並啟動。
3. 在各語音頻道檢查機器人的「設定語音頻道狀態」權限；若要在離開後清除狀態，可另外授予「管理頻道」。缺少此權限仍可播放音樂。
4. Python 部署重新執行 `python3 main.py`；播放歌曲或使用 `/nowplaying` 產生新版卡片，確認控制選單與語音頻道狀態。

無須新增環境變數、相依套件或手動遷移資料庫；專案既有需求已包含 discord.py 2.7 以上。原有斜線指令繼續可用。
